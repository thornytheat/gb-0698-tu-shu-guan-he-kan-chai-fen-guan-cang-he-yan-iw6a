# 期刊记录定义

record_id、copy、volume作为字符串保留前导零。ISSN检查8位格式，不校验国际注册关系。title支持本仓内别名字典。year范围1900—2100。

issue支持1、1-3、3/4以及S1。连字符表示含两端的期号范围，斜线表示列举（可多段）。常规期号1—24；增刊不计入常规年度12期。status取held、suspended、missing。held实际册由ISSN+年度+复本+binding唯一确定；合刊一册可覆盖多期。同复本同一期处于不同binding时报装订冲突。

跨年合刊用斜线列举并给每段显式标注年度，如`2025:12/2026:1`：各段年度须连续递增，且记录year须落在覆盖年度之内。写法混杂（有的段带年度有的不带）、年度不连续、记录年度不在覆盖范围内，分别进入CROSS_YEAR_FORM、CROSS_YEAR_SEQUENCE、CROSS_YEAR_ANCHOR隔离，不混入正式结果。跨年合刊只占一册：每个期次按自身年度计入该年覆盖与缺期，实体册只在记录年度（归集年度）计一次。同一刊同一复本同一装订号被不同年度分两行登记时，记CROSS_YEAR_SPLIT冲突并阻断复核，须合并为一行跨年写法后重报；晚到的修正记录与已确认覆盖冲突时按装订冲突列出双侧证据，不改写已确认覆盖。

缺期=1至12减去已持有期减去明确停刊期。缺期是补录任务，并非质控阻断；装订和刊名身份冲突阻断复核。馆藏输入行数与覆盖期次、实体册分别对账。

held记录必须有binding装订号，缺失进入BINDING_REQUIRED隔离，不得把空装订号的多册合并。
